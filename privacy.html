Privacy Policy

ytauto uploader · Effective date: October 13, 2026

Who this applies to

ytauto uploader is a personal tool used by a single creator to upload their own videos to their own YouTube channel. It is not offered to the public and does not collect data from anyone else.

Google and YouTube data the app accesses

With the creator's consent, the app requests one Google OAuth scope: https://www.googleapis.com/auth/youtube.upload. It uses this access only to upload videos the creator produced, and to set their metadata (title, description, privacy status) on the creator's own channel. It does not read viewers' data, comments, analytics, or any other account information.

How credentials are stored

The OAuth client credentials and the refresh token are stored only as encrypted secrets in the creator's private GitHub repository, where they are used by the creator's own automation to perform uploads. They are not written to logs, not shown in build output, and not stored anywhere else.

Sharing

No data obtained through Google APIs is sold, shared with, or transferred to any third party, and it is not used for advertising or for training AI models.

ytauto uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Credentials are kept until the creator revokes them. Access can be revoked at any time on the Google Account permissions page: myaccount.google.com/permissions, after which the stored refresh token stops working and is deleted from the repository secrets. Rendered video files used for an upload are kept only as temporary build artifacts in the creator's private repository.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Changes

If the data the app accesses changes (for example, adding caption uploads), this page will be updated before the new access is requested.
