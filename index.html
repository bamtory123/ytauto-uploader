ytauto uploader

A personal tool for one YouTube channel.

ytauto uploader is part of a private video production pipeline run by a single creator. It uploads videos that the creator produced with that pipeline to the creator's own YouTube channel, using the YouTube Data API.

  • It is not offered to other people and does not accept other users' accounts.
  • It requests only the YouTube permission needed to upload videos (youtube.upload).
  • Uploads are created as private by default; publishing is a separate, manual decision by the creator.
