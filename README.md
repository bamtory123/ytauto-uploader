# ytauto uploader

Homepage and privacy policy for **ytauto uploader**, a personal OAuth client that uploads the owner's own videos to
the owner's own YouTube channel. Served with GitHub Pages:

- https://bamtory123.github.io/ytauto-uploader/
- https://bamtory123.github.io/ytauto-uploader/privacy.html

This repository contains no code and no credentials.
